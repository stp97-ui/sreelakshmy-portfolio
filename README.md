# Sreelakshmy TP Portfolio

A responsive React + Vite developer portfolio inspired by the modern dark portfolio style you shared.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Before publishing

1. Replace `YOUR_EMAIL@example.com` in `src/main.jsx`.
2. Replace the LinkedIn and GitHub placeholders.
3. Put your real resume at `public/resume.pdf`.
4. Replace project images/descriptions with your actual project details.
5. For the professional insurance project, avoid confidential client/company data.

## Deploy to Vercel

Push this folder to GitHub, import the repository into Vercel, and use:
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`
